Computer System Architecture & Hardware Components Computer Science • Form Factor • High-Speed Bus Communication

A computer system is composed of hardware components working in synchrony: the CPU (Central Processing Unit) computes operations, RAM provides volatile high-speed execution space, the Motherboard connects all units via high-frequency PCIe and data buses, and storage devices retain permanent data.

Central Processing Unit (CPU)

The "Brain" of the computer containing the ALU (Arithmetic Logic Unit), Control Unit (CU), and ultra-fast L1/L2/L3 on-die Registers and Caches.

Clock Cycle & Throughput: $f = rac{1}{T}$ • $ ext{Instructions Per Second} = ext{Clock Speed} imes ext{IPC}$ Modern multi-core processors execute billions of instructions per second per thread.

Random Access Memory (RAM)

High-speed volatile semiconductor memory that holds code and variables currently executed by active OS processes. Data is lost upon power loss.

  • DDR5 Bus Speeds: Exceeds 6400 MT/s offering over 50 GB/s bandwidth per channel.
  • Byte-Addressable: Each memory cell holds 8 bits (1 byte) identified by a 64-bit hexadecimal address.

Graphics Processing Unit (GPU)

Massively parallel computing chip with thousands of stream cores designed for matrix multiplication, 3D polygon shaders, and AI/tensor computation.

Non-Volatile Storage (NVMe SSD / HDD)

Permanent storage utilizing NAND flash transistors arranged in 3D TLC/QLC cell blocks, connected directly to CPU lanes via PCIe Gen 4/5 NVMe protocol.

Motherboard & Power Supply (PSU)

The main printed circuit board (PCB) featuring the chipset, VRMs (Voltage Regulator Modules), clock generator, BIOS/UEFI ROM, and standard expansion slots.

Von Neumann Architecture (1945)

The universal model of modern digital computers where program instructions and data share the same addressable memory.

1. Fetch

The Control Unit fetches instruction word from memory at Program Counter (PC) address into Instruction Register (IR).

2. Decode

Opcode decoder determines required operation, ALU inputs, and register operand pointers.

3. Execute & Writeback

ALU performs integer/float computation and writes outcome into accumulator or registers.

Computer Memory & Storage Hierarchy

Balancing extreme speed, bandwidth cost, and persistence across modern memory tiers.

L1/L2 Cache (~1 ns)

SRAM cells inside core, zero latency for current loop counters.

RAM (~50-80 ns)

DRAM capacitor banks, 16-64 GB active memory capacity.

NVMe SSD (~20-50 µs)

3D NAND flash memory, terabytes of non-volatile file storage.
