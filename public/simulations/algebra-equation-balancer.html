An algebraic equation states that two expressions are equal ($LHS = RHS$). Like a dual-pan mechanical balance scale, whatever mathematical operation is applied to one side must be equally applied to the other side to preserve equality.

Axioms of Equality

  • Addition Property: If $a = b$, then $a + c = b + c$.
  • Subtraction Property: If $a = b$, then $a - c = b - c$.
  • Multiplication Property: If $a = b$, then $a \times c = b \times c$ ($c \neq 0$).
  • Division Property: If $a = b$, then $a / c = b / c$ ($c \neq 0$).

Step-by-Step Solving Strategy

Goal: Isolate $x$ on one side of the equal sign Example: $2x + 3 = 11 \rightarrow$ Subtract 3 from both sides: $2x = 8 \rightarrow$ Divide by 2: $x = 4$

Slope-Intercept Geometry

In $y = mx + b$, $m$ represents the rate of change (slope) and $b$ denotes the initial value ($y$-intercept at $x=0$).

Real-World Utility

  • Finance & Breakeven: Equating Revenues to Fixed Costs + Variable Costs to determine minimum sales volume.
  • Physics (Kinematics): Rearranging $v = u + at$ to solve for acceleration $a = (v - u) / t$.

Linear Functions on the Cartesian Plane

A linear equation $y = mx + b$ graphs as a straight line with slope $m = \frac{\Delta y}{\Delta x}$.

Positive Slope ($m > 0$)

Line rises from bottom-left to top-right. As $x$ increases, $y$ increases.

Negative Slope ($m < 0$)

Line falls from top-left to bottom-right. Inverse relationship.

Y-Intercept ($b$)

The coordinate $(0, b)$ where the line intersects the vertical $y$-axis.

Key Algebraic Manipulations

Common techniques for simplifying complex multi-step equations.

Combine Like Terms

Add coefficients of identical variable terms ($3x + 5x = 8x$).

Distributive Expansion

Multiply external factor across parentheses: $2(x + 4) = 2x + 8$.

Cross-Multiplication

For fractions $\frac{a}{b} = \frac{c}{d} \rightarrow ad = bc$.
