🌳 What is a Binary Search Tree (BST)?

A Binary Search Tree is an ordered node-based data structure where each node contains a key and at most two child pointers (Left and Right). It enforces the BST Invariant:

  • Left Subtree: All node keys in the left child tree are strictly smaller than the parent node (< key).
  • Right Subtree: All node keys in the right child tree are strictly greater than the parent node (> key).
Search & Insert (Average):
O(log N) logarithmic time on balanced trees.
Search & Insert (Worst):
O(N) linear time when degenerate (skewed list).
Space Complexity:
O(N) storing exactly N pointers and values.
In-Order Traversal Property:
Visiting Left → Node → Right produces a strictly sorted ascending array!

🔄 The 4 Classic Tree Traversal Algorithms

1. In-Order (L - N - R):
Recursively visit Left child, current Node, then Right child. Used to read all elements in ascending sorted order.
2. Pre-Order (N - L - R):
Visit current Node first, then Left child, then Right child. Ideal for duplicating/serializing tree topology.
3. Post-Order (L - R - N):
Visit Left child, Right child, then current Node. Fundamental for bottom-up node deletion, memory deallocation, and expression trees.
4. Breadth-First / Level-Order:
Visit nodes level by level (Root → Depth 1 → Depth 2) using a FIFO Queue. Used in shortest path algorithms and BFS.
