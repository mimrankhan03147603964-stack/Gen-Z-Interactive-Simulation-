Computer Keyboard Shortcuts & System Hotkeys Computer Science • Ergonomics • Rapid Workflow Automation

A keyboard shortcut is a key or combination of keys (using modifiers like Ctrl, Alt, Shift, and Win/Cmd) providing quick access to software functions otherwise reachable only through nested mouse menus, increasing user productivity up to 10-fold.

Universal Clipboard & History Operations

Essential across all word processors, file managers, code editors, and browsers:

Ctrl + C / Ctrl + X

Copy selection to clipboard memory or cut (remove and copy) active content.

Ctrl + V

Paste buffer contents into the current insertion cursor position.

Ctrl + Z / Ctrl + Y

Undo last buffer mutation or redo previous reverted operation.

Multitasking & Window Management

  • Alt + Tab: Task Switcher - cycle through active application windows.
  • Win + D: Show Desktop - minimize/restore all open application windows immediately.
  • Ctrl + W: Close active browser tab or document without terminating application.

Operating System Diagnostic Hotkeys

  • Ctrl + Shift + Esc: Directly launches Windows Task Manager.
  • Win + L: Immediately locks the workstation and protects user session.
  • Win + Shift + S: Launches interactive Snipping Tool for region screenshot captures.

Typography & Document Formatting

  • Ctrl + B: Toggle Bold emphasis on selected text.
  • Ctrl + I: Toggle Italic font slant.
  • Ctrl + U: Toggle Underline decoration.

Operating System Shortcuts (Windows & Mac)

Speed up desktop navigation without touching the mouse.

Win + E

Launches File Explorer directly to Quick Access / This PC.

Win + Arrows

Snap active window to Left, Right, Top (Maximize), or Bottom.

Win + . (Period)

Opens the Windows Emoji, Symbol, and Kaomoji Picker.

Web Browser & Office Productivity

Every second saved on repetitive tasks compounds into hours over workweeks.

Ctrl + T / Ctrl + W

Open a new browser tab / close current browser tab.

Ctrl + Shift + T

Re-opens the last closed browser tab (Emergency restore).

Ctrl + F

Find on page / search document text occurrences instantly.
